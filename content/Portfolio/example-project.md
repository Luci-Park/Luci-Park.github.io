## Overview

This is a placeholder portfolio entry to demonstrate the card grid layout on the Portfolio index page.

Replace this file with your actual project writeups. Each file under `content/Portfolio/` will automatically appear as a card on the [[Portfolio/index|Portfolio]] page.

## Frontmatter fields used by the card

| Field | Purpose |
|---|---|
| `title` | Card heading |
| `description` | Short summary shown on the card |
| `socialImage` | Cover image (16:9 aspect ratio recommended) |
| `tags` | Tag pills shown at the bottom of the card |
